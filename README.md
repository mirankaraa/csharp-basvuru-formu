
# C# Windows Forms - Başvuru Formu

## 📌 Proje Hakkında

Bu proje, C# ve Windows Forms kullanılarak geliştirilmiş basit bir başvuru formu uygulamasıdır.

Projenin amacı, Windows Forms üzerinde öğrendiğim temel kontrolleri ve kullanıcı etkileşimlerini uygulamalı olarak geliştirmek ve pekiştirmektir.

## ✨ Uygulama Özellikleri

- Ad ve soyad bilgisi alma
- E-posta ve telefon numarası alma
- RadioButton ile cinsiyet seçimi
- CheckBox ile programlama dili seçimi
- Button ile form gönderme işlemi
- MessageBox ile bilgilendirme mesajı gösterme
